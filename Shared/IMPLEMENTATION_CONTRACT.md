# Current lifecycle contract: desktop 0.3.2 / plugin 0.2.6

User choices and applied effects are independent. GameAdapter.Settings returns immutable requested choices; hooks use the private effective _settings. SuspendEffects restores world/actor modifications without clearing choices. RefreshEffects(controlActive) resumes only for a ready local actor and filters current capabilities, cached by settings identity and capability revision. Reset and Dispose clear requested choices. Scene/actor/readiness transitions only suspend/refresh, never reset configuration. Disconnect/timeout pauses effects until the same desktop controllerId queries again; a different controllerId starts disabled. State revisions still invalidate stale queued changes; explicit reset also increments the revision. Snapshot features report requested switches/values plus current availability. Missing availability never silently clears the selected switch. Wire protocol remains v2 with additive controllerId metadata.

The historical contract below describes the earlier 0.2.0 baseline; its actor/scene/disconnect-reset requirement is superseded by the user-requested behavior above.

## Historical 0.2.0 integration contract

FeatureDefinition: Id,Name,Group,Description,Unit,HasValue,Min,Max,Default,Step. FeatureCatalog.All, Find(id), StatusNames. FeatureValue: id,enabled,value,available,reason.
FeatureSettings now implemented by parent: Enabled(id)/IsEnabled(id), Value(id)/GetValue(id), Factor(id), AnyEnabled, ToWire(), Defaults(), constructor FeatureValue[]; immutable cloned state. Complete 51-entry state required; unknown/duplicate/missing/nonfinite/out-of-range values rejected.

GameAdapter shared world methods: InitializeWorld(Assembly assembly,Harmony harmony), ResetWorld(), TickWorld(), DisposeWorld(). World agent must coordinate with core agent on these exact calls.
TrainerPlugin parent owns; handles all-feature set/reset/snapshot and AnyEnabled fail-safe. Please expose public Tick() for parent to call once per Update after lifecycle resets. Tick() can invoke TickWorld and actor transient restore logic. Parent will call _game.Tick().
Core agent owns GameAdapter.cs and actor supporting files; world agent owns GameAdapter.World.cs; UI agent owns Desktop MainWindow.xaml/.cs and PipeClient response array validation. Parent owns protocol, catalog, settings, tests, packaging and TrainerPlugin.
Version 0.2.0. No game launches. All functions default off; preserve own-unpatch only, stop IPC acknowledgement, actor/scene/disconnect reset. Every stored game object must have bounded lifetime and restore/release on Reset/Dispose. Game runtime not yet tested.
