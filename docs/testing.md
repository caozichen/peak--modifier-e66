## 可选的旧版实际程序集分析工具

`validation/game-assembly/` 与 `scripts/Test-GameAssembly.ps1` 保留历史只读接口/IL 分析入口：加载自己的游戏程序集及插件，不调用 Harmony.Patch，不启动游戏、不执行游戏方法。它不在标准七组 Test.ps1 中。

本次 .NET 10 宿主运行该旧工具得到 **26/35**，9 项在 Harmony 读取原始指令或相关分支检查时出现 `NotSupportedException: Body-less method`（有一项被反射异常包装）。这部分**尚未完成宿主兼容修复**，不能视为 35 项通过，也不能仅据此判断游戏中功能已失效。真实游戏内的接口/补丁能力以插件日志和逐项实测为准。若继续维护该分析工具，应先处理 Mono 游戏程序集在当前宿主的指令读取方式，再解释游戏版本差异。

运行方式：

```powershell
.\scripts\Test-GameAssembly.ps1 -GameDir $env:PEAK_GAME_DIR
```

`legacy/Upgrade.Tests.ps1` 另外需要自行提供旧 0.2.5 DLL，故不作为仅克隆新仓库就能完成的默认检查。旧升级脚本只有搭配其原发行包布局、清单才可使用。

## 真实游戏测试矩阵

| 场景 | 预期 | 主要观察 |
| --- | --- | --- |
| 新窗口和新游戏进程 | 所有功能关闭 | 不从磁盘自动恢复开关 |
| 机场可控制角色 | 就绪，支持的控件可用 | 不依赖登山统计对象 |
| 移动/攀爬/跳跃/抗摔 | 最低值不变，最高 200 | 逐项调节，观察地形/碰撞影响 |
| 标记手势 | 最大 50 | 开启/关闭后的大小恢复 |
| 体力和状态 | 按开关与组合倍率生效 | 0、默认值、上边界、阻止与清除区别 |
| 一键清除 | 一次生效，不改变持续选择 | 诅咒/石化/荆棘，持续来源再次施加 |
| 机场→地图→结算回机场，多轮 | 选择和倍率保留，加载期间暂停 | 就绪后恢复效果 |
| 死亡/昏迷/新角色 | 暂停并保留选择，恢复后重新应用 | 旧角色对象不残留引用 |
| 同窗口短暂断线与恢复 | 选择保留，重连先查询，不重放清除 | 旧请求应被拒绝 |
| 房主权限变化 | 对应效果暂停/恢复，不清除选择 | 非房主不能修改迷雾推进 |
| 手动恢复全部 | 清空选择，旧排队操作不重新开启 | 状态修订号 |
| 停用插件 | 自身补丁撤销，回执后断开，窗口已停用 | 其他 Mod 不受影响 |
| 退出/重进游戏 | DLL 随退出释放，新会话关闭 | 不重复加载，不残留后台服务 |
| 安装、更新、卸载 | 关闭游戏时操作，保留其他 Mod 与配置 | 卸载仅处理本目录拥有的未改文件 |

## 内存与句柄观察

保持游戏和窗口运行，反复进行场景往返、开关、连接恢复、恢复全部和停用；定期记录游戏/桌面内存、句柄、线程、日志增长与缓存数量。关注完成一个循环后是否持续只增不降，结合 GC 和游戏本身资源加载解释数据。替身检查验证了已覆盖路径的有界缓存与恢复逻辑，但不能证明任意游戏版本、组合、长时间运行都没有泄漏。

本次源码整理没有新增真实游戏实测结论，也没有修改已部署游戏文件。
