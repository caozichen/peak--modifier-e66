# 使用说明

1. 将整个文件夹解压到可写位置，双击 `PeakWorkshop.exe`；也可以在 CMD 中执行 `Launch.cmd`。无需安装 C#、.NET 或开发工具。
2. 首次使用先退出 PEAK，在“游戏与插件”中扫描 Steam 安装目录；必要时手动选择。
3. 点击“安装游戏插件”，等待检查、备份和安装完成。程序不会自动启动游戏。
4. 从 Steam 启动 PEAK，角色就绪后逐项开启功能。侧边菜单跳转同一个完整列表，列表滚动同步菜单。
5. 一键清除当前状态在顶部；该按钮仅执行一次，持续来源可能让状态重新出现。
6. 同一窗口、同一游戏进程内的机场往返保留开关与倍率，加载时暂停效果，角色就绪后恢复。短暂失联保留选择。
7. “恢复全部”关闭功能；“停用插件”关闭功能并撤销本插件补丁、停止通信，窗口显示已停用。重启游戏才能重新加载插件。DLL 随游戏退出释放。
8. 再开一个新窗口、重启窗口或重启游戏，会从关闭状态开始；磁盘设置只保存游戏路径与有效倍率，不自动开启功能。

`logs/` 保存窗口日志及主动收集的诊断；`settings.json` 保存本机设置；`backups/` 保存安装记录和备份。请保留整个目录，卸载前关闭游戏并在“游戏与插件”里操作。旧 CMD 升级安装使用旧包的卸载入口，界面不会自动接管旧包记录。

右上角可查看游戏与修改器版本，悬浮查看完整程序集 SHA256，点击复制。历史版本 Hash 不匹配不会阻止使用；具体功能仍取决于当前游戏接口和权限。

安装遇到冲突时按提示处理，不要手动覆盖未知加载器。目录权限不足时可选择可写安装位置，或按实际需要以管理员权限再次运行。程序不要求日常始终以管理员运行。

分享给朋友时请发送新生成的干净目录或原始 ZIP，不要携带你使用后的日志、设置、备份。
