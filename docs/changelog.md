# 当前开发线变更记录

## 桌面 0.3.2 / 插件 0.2.6

- 用户选择与实际生效配置分离；机场→地图→机场、角色重建、死亡/昏迷、同窗口暂时失联时保留开关和倍率。
- 角色未就绪或能力/房主权限暂不可用时暂停相应效果，恢复后重新应用。
- 窗口独立 controllerId；新窗口接管默认关闭，旧排队修改仍按状态修订拒绝，单次清除不重放。
- 右上角增加游戏 Steam Build、程序集 SHA256 与修改器/历史基线信息，可复制完整 Hash。
- 悬浮提示显式深色背景/浅色文本及换行，轮询复用对象，修复默认样式导致的白底白字。

## 桌面 0.3.1 / 插件 0.2.5

- 移除实际游戏程序集 SHA256 的版本白名单，不因游戏更新而禁止安装或尝试初始化。
- 保留每项游戏接口/IL 匹配、参数、通信和安装文件完整性检查。

## 桌面 0.3.0 / 插件 0.2.4

- 自包含便携目录、Steam 发现/手动选择、首次安装、更新卸载、文件事务恢复、日志收集。
- 顶部独立一键清除当前状态。
- 移动、攀爬、跳跃、抗摔上限 200，原最低值不变；标记手势上限 50。
- 名称改为用户易懂表述；侧边菜单锚定完整列表，滚动同步高亮。

## 插件 0.2.1–0.2.3

- 修复 Unity Mono 命名管道/JSON 兼容、桌面连接和本地角色识别。
- 机场本地角色就绪不再被登山统计对象的存在与否卡住。

## 插件 0.2.0 及更早

- 从早期两项功能扩充到完整 51 项持续控制。
- 引入分项能力报告、完整设置快照、主线程请求和只撤销自身补丁的停用流程。

## 源码仓库整理

保留上述最新生产行为；补充可传入路径的构建/发布入口、所有验证工程和当前文档，移除构建引用对个人路径的依赖。构建可能因路径/生成元数据产生不同插件哈希，Build 会同步内嵌策略；不会自动替换用户已安装的插件。
