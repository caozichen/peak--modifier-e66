# 功能清单

桌面 0.3.2 / 插件 0.2.6。共 51 项持续控制；有数值的条目也必须开启开关才产生效果。定义以 `Shared/FeatureCatalog.cs` 为准。所有数值项初始值为 1，所有开关初次启动默认关闭。

## 独立一键清除

`clear_status` 不在 51 项持久配置中。调用顺序：`SetPetrify(0)`、`RemoveAllThorns()`、`ClearAllStatus(false, false)`，执行前重新校验本地角色和组件归属。该操作不改变开关、不自动重试、不在场景切换或重连时重放。持续环境/物品负重/螃蟹等来源可能重新施加状态。

## 组合与边界

- 总体体力消耗与攀爬体力消耗同时开启时倍率相乘；无限体力按其对应规则优先生效。
- 全局和单项状态倍率相乘；“不再增加”优先；清除已有状态使用独立按钮。
- 迷雾推进的暂停与速度需要当前房主权限；本地看穿迷雾不代表改变其他人的显示。
- 关闭功能会停止持续影响并恢复可撤销的临时值，不倒退已推进的迷雾、不补回已消耗的物品或燃料。
- 移动、攀爬、跳跃、抗摔上限 200；标记手势上限 50；具体效果还受物理、地形和游戏逻辑影响。
- 场景切换只暂停效果并保留选择；缺失接口时报告具体原因，不因历史游戏 Hash 不同一概禁用。
